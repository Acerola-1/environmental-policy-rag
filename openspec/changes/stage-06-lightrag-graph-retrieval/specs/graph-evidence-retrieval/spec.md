## Purpose

通过固定版本 LightRAG 取得可追溯的实体与关系来源候选，将其映射到既定快照内的原文块，与既有检索进行去重和排名融合。以同语料、模型与预算规则的 A/B/C/D 消融衡量图的独有有效条目、错误和费用，不将图摘要视为证据，也不预设图必然提升质量。

## ADDED Requirements

### Requirement: 固定版本与能力核验门槛

图接入 MUST 记录明确的 LightRAG 版本/提交、依赖及配置，并在该版本核实转换格式、hybrid 来源候选、图后端隔离/更新/删除能力。系统 SHALL 将缺失能力列为阻塞或受限项，不得把 main 文档、未验证后端或 RAG-Anything 当成已支持的事实；解析转换不得隐式触发构图或额外模型调用。

#### Scenario: 核验通过后冻结接入配置

- **WHEN** 获准核验的固定版本可输出可定位的来源候选，且所选后端满足已声明的隔离要求
- **THEN** 交付准确版本、配置、脱敏响应及后端选择依据；只有实际需要并获准时才纳入额外转换依赖。

#### Scenario: 能力缺失或调用未授权

- **WHEN** 固定版本不能提供所需来源映射，或构图/模型/新增部署未获授权
- **THEN** 系统记录阻塞而不伪造来源，不自动安装图数据库、引入 RAG-Anything、构图或发起模型请求。

### Requirement: 图候选必须回到快照原文

系统 SHALL 保留实体/关系来源 chunk 到 PG 的 doc_id、内容版本、解析版本和 block_id 的完整映射，并在检索与最终引用时校验 scope/snapshot。图 summary MUST NOT 被当作政策原文证据；映射缺失、越界或错版本的候选 MUST 被隔离并记录原因。

#### Scenario: 多来源关系返回原文引用

- **WHEN** 一条关系的来源 chunk 对应当前快照内多个原文块
- **THEN** 系统返回这些块的定位、版本、quote 和页码，保留来源链；最终条目的语义支持可独立复核，不引用关系摘要充数。

#### Scenario: 旧版本或孤立来源被拒绝

- **WHEN** 图候选仅有生成 summary、来源 chunk 无映射，或映射指向当前 scope/snapshot 外版本
- **THEN** 候选不进入已验证证据集合，拒绝 trace 标明具体原因，系统不以当前同名实体的其他原文替代。

### Requirement: 图与外部向量无重复信号融合

系统 MUST 使用经核实的 hybrid 图来源候选，先按原文身份路内去重，再与独立词法/外部向量路执行应用层 RRF，保留路内 rank、参数和贡献。相同块 SHALL 只占一个融合候选位置；外部向量已启用时，系统 MUST 拒绝 mix 重复向量加权配置，不得把 LightRAG 原生融合冒称 RRF。

#### Scenario: 重复实体命中只贡献一次图路排名

- **WHEN** 多个实体和关系命中同一个块，且独立外部向量路也命中该块
- **THEN** 该块在图路只有一个有效 rank、融合后只有一份候选，保留图与向量各自一次独立路贡献及全部来源记录。

#### Scenario: mix 与外部向量重复组合被拦截

- **WHEN** 配置试图在已有外部向量路之外启用含重复向量信号的 mix
- **THEN** 系统在执行前拒绝该组合并说明原因，不通过最终答案去重来掩盖检索排序的重复加权。

### Requirement: 范围不扩张与图失败可见

图路径 SHALL 保持 A/C 已确认的 scope 和 snapshot，D 不得用图命中缩减 C 遍历范围或自动加入范围外文件。图失败 MUST 返回显式错误或带实际路线、原因的 A/C 降级结果；重试有界且降级不得统计成成功执行图路线。

#### Scenario: 图发现范围外政策线索

- **WHEN** D 发现不属于已确认范围或内容版本的关联文件
- **THEN** 当前枚举仍遍历原定全部范围，不把该线索计入答案或收益；若展示建议则标明范围外，确认后只能开启新范围任务。

#### Scenario: 图查询失败后显式回退

- **WHEN** 图路超时或后端不可用，且已配置允许回退基线
- **THEN** 返回 A/C 的实际结果并标明 graph_status、失败原因和执行路线，保留错误与重试成本，不把回退题从评测删除。

### Requirement: 公平消融与负收益结论

本阶段 MUST 在已验收 A 与 C 上比较 A/B/C/D，冻结同一语料、快照、分块、模型、重排、生成及缓存策略；A/B 固定上下文预算，C/D 固定完整扫描与预算规则，显式记录额外图与枚举开销。验收 SHALL 保留全题预测、独立裁决、独有有效项、新增错误/损失项以及构建/查询 token、时间和费用，允许无收益或负收益结论，不将其伪装成提升。

#### Scenario: 完整四组实验可归因

- **WHEN** stage-04 与 stage-05 已验收且另行授权的固定题集实验完成
- **THEN** 提供 B 相对 A、D 相对 C 的唯一正确条目及证据、配置差异、全题质量指标、失败/降级分组和独立构建/查询成本，公开与合成分开统计。

#### Scenario: C 尚未就绪或图无收益

- **WHEN** 只有 A/B 子实验，或完整实验发现图没有独有有效项、降低质量或成本过高
- **THEN** 缺 C 时明确 C/D 和完整阶段验收未完成；实验无收益时保留原始证据并允许“不采用/暂缓”结论，不补造分数、剔除失败题或宣称必然提升。
