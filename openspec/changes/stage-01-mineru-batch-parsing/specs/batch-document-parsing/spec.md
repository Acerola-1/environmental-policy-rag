# Spec Delta

## Purpose

为环境政策与标准文件提供受授权范围约束的批量解析能力，保留原始资料、完整结构化结果和可恢复任务记录，使后续原文入库能够追溯来源、识别缺页与缺资源，并避免重复提交带来的费用和错误完成状态。

## ADDED Requirements

### Requirement: 显式限定解析范围与费用

系统 MUST 仅提交经确认且与来源清单哈希一致的样本；在凭证、服务协议或额度条件不满足时不得发送文档。首批范围为air-01、water-02、air-03，共28页，不包含其他样本。

#### Scenario: 首批范围正确
- **WHEN** 首批3份文件哈希、凭证及免费额度条件均已核实
- **THEN** 提交范围仅包含这3份文件，并留下样本ID、页数及配置记录

#### Scenario: 意外扩量或额度不足
- **WHEN** 待提交列表包含额外文件、哈希不符、凭证缺失或需要新增费用
- **THEN** 系统拒绝相应提交并返回可处理原因，不自动改用其他外部服务

### Requirement: 解析结果与原件可追溯且互不覆盖

系统 SHALL 保留原PDF及其哈希，并将未经清洗的解析包、结构化结果及配套资源关联到准确样本和解析配置；不得以Markdown单文件或生成摘要替代完整结果交付。

#### Scenario: 完整结果到达
- **WHEN** 服务提供有效ZIP结果且文件检查通过
- **THEN** 原PDF内容不变，ZIP及解压资源可按样本定位，源与结果哈希及实际输出协议可查询

#### Scenario: 只取得Markdown
- **WHEN** 返回结果缺少预期JSON或引用的资源
- **THEN** 系统记录缺失项并标为未通过结构化验收，不把该样本当作完整可入库产物

### Requirement: 恢复不盲目重复提交

系统 MUST 保存每份样本的处理意图、已知任务标识及状态，并在有限重试/轮询后停止；不得把客户端超时解释为远端未创建任务。

#### Scenario: 已提交任务后重启
- **WHEN** 重启时发现相同源与配置的已知任务记录
- **THEN** 系统恢复查询或下载，而不是创建第二个解析任务

#### Scenario: 提交结果不确定
- **WHEN** 提交响应在返回任务标识前中断，无法确认远端是否接收
- **THEN** 系统保留不确定状态并要求核对，禁止自动重提

### Requirement: 安全处理外部资源与秘密

系统 MUST 拒绝解压路径越界、符号链接及超过配置资源限制的结果包；凭证和可用签名链接不得进入日志、报告或命令参数，也不得随下载请求发送给其他主机。

#### Scenario: ZIP中存在越界条目
- **WHEN** 结果包包含绝对路径、上级目录逃逸或符号链接
- **THEN** 系统拒绝提取，样本目录之外没有新增或覆盖文件，并记录脱敏错误

#### Scenario: 请求或下载失败
- **WHEN** 外部请求失败并形成错误日志
- **THEN** 日志可定位样本与失败阶段，但不包含密钥、Authorization或可直接访问资料的签名URL

### Requirement: 缺口可观察且批次状态真实

系统 SHALL 为每份样本记录页码与资源完整性检查、人工抽查项及失败状态，区分下载成功、结构检查通过和内容抽查通过；一个文件失败不得使其余文件结果丢失或使整批被错误标为通过。

#### Scenario: 部分样本失败
- **WHEN** 三份中两份成功、一份超时或资源损坏
- **THEN** 报告保留所有三份记录，明确失败样本及恢复起点，整批不得显示全部通过

#### Scenario: OCR遗漏脚注或条件
- **WHEN** 原PDF表格存在脚注或单位但解析结果没有保留
- **THEN** 检查记录标出原物理页与缺失内容所在位置，样本不得以页数相符为由通过内容验收
