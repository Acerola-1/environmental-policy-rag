## 3. Extraction and Recovery

- [ ] 3.1 建立保留类型、对象、条件、数值、单位、时间、版本与 evidence 的条目契约，变更实际数据契约前另行取得实现授权；验收：表格及脚注保真、未知字段和多证据条目样例及对应验证测试。
- [ ] 3.2 实现重复条目合并与差异条件保留，记录去重前后和出处；验收：完全重复不多计，不同阈值/单位/适用时间不误并的对照测试。
- [ ] 3.3 核验 block_id、quote、页码、内容/解析版本及语义支持，隔离无支持候选；验收：正确引用、缺引用、错版本、原文存在但不支持结论的测试与独立复核记录。
- [ ] 3.4 持久化 pending/processed/failed、空相关项、尝试次数及批次结果，支持幂等汇总；验收：批次提交前后中断、重复回传和恢复测试，状态集合互斥且与预期块总数一致。
- [ ] 3.5 实现 partial/error、预算停止、剩余范围与分页续接，必要时再评估 LangGraph 或其他编排；验收：未处理/失败/缺解析块均不假 complete，重复恢复无重复条目，遍历完成与语义覆盖分开显示。
