## 3. Readback and Verification

原文参考：[步骤](../../../docs/04-step-by-step.md)、[契约](../../../docs/05-data-contracts.md)、[验收](../../../docs/07-acceptance-and-evidence.md)。真实 PG 不可用时本组集成验收必须标阻塞，不拿 SQLite 替代。

- [ ] 3.1 实现固定内容及解析版本的有序游标读取；验收：有限页大小遍历所得 ID/数量/顺序与已保存集合完全一致，首尾页、跨章节、表格和附件均可定位。
- [ ] 3.2 验证游标与历史版本边界；验收：空集合、未知版本、非法页大小、跨版本/跨解析游标和遍历中默认解析切换均有确定结果，合法历史读取不混入新版本。
- [ ] 3.3 实现并验证父章节扩展；验收：按序只返回同版本同解析视图的章节块，无父、非法父、循环及越界引用可区分，父章节不冒充全文。
- [ ] 3.4 扩展现有契约校验及回归测试并完成真实 PG 集成验证；验收：旧 smoke 保持兼容，正常、失败、重复、回滚和版本边界测试留下实际日志，模拟或 SQLite 结果单独标注不能抵充 PG 验收。
