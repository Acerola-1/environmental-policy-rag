角色：公司项目成员。时间：2024.03 — 2026.09。

## 简历正文

面向数智大气场景，建设覆盖大气、水环境政策、公文、标准及地方公开数据的 RAG 知识库，为政策条款、治理措施和气象标准定义等查询提供可追溯的原文依据；重点解决政策问答中跨地区、跨版本、跨文件与跨段落条件下的信息完整性问题。

- **多路检索与完整性查询：**针对定义、标准等普通问答，结合稠密/稀疏检索与 LightRAG 图关系候选，经 RRF 融合和 Rerank 筛选原文；针对政策措施清单等需要查全的问题，先解析地区、时间和版本范围，再按文件与章节读取、抽取和汇总，避免仅依赖 Top-K 召回造成跨文件遗漏。
- **版本化增量更新：**以内容哈希识别新增与修订，驱动解析、向量和图索引的幂等更新；新版本完成索引与原文映射校验后再切换知识快照，保留历史版本并支持失败重试、废止政策与历史查询。
- **确定性问答缓存：**对范围、知识快照和模型配置一致的标准定义类问题，通过 Redis 精确缓存直接复用带出处的完整答案，跳过检索流程；结合版本失效和同 key 请求合并，减少重复检索、生成与并发回源。
- **项目成果指标：**检索 Recall@20 ≥90%；在 5 并发、输出不超过 512 Token 的短问答条件下，首 Token P90 ≤2s、完整响应 P50/P90 ≤4s/8s；对范围与知识版本一致的重复问题，精确缓存命中响应 P90 ≤0.5s，在含 50% 可复用问题的受控回放中，正确复用请求占比 ≥45%。

## 事实边界（本目录仍以事实版为准）

- 本文件的正文属于**目标预演稿**：LightRAG 图检索、版本化增量更新、Redis 缓存与上述指标均为**预设目标与设计**，尚未在公司项目中实现，不得写进事实版简历或表述为已实测成果。
- 既有公司项目事实不变：约 4.4 万份环境政策、标准和治理措施文件；MinerU 解析、分块入库、混合检索、RRF 融合、Rerank 精排和父章节召回；已完成正式业务交付。
- “50% 可复用请求回放、正确复用率 ≥45%”的含义：测试请求中预置一半为可安全复用的重复问题，系统至少正确复用全部请求中的 45%。
